# Content writing profiles

Research reviewed 2026-10-28:
- https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews

These sources support reader-first coverage, original value, evidence-backed
claims, and comparisons using relevant criteria rather than a target word count.
They do not prescribe our six templates or guarantee rankings.

Blog: step-by-step guide, comparison, troubleshooting.
Site pages: reference article, service description, product description.
Each selects a separate editorial instruction. A reference article remains
informational; it is not automatically treated as a service landing page.

The editor stores the profile and a 400-character audience/goal/evidence brief
with the existing project-scoped local draft. Legacy drafts use defaults.
The current project's server-side SAM context and research still supply the
business context and observed metrics. A user brief is not verified evidence.

All profiles retain duplicate-content checks and the existing review-before-CMS
draft flow. The prompt remains below the 4,000-character API limit, including
when the source page or notes are long. Templates guide generation; they do not
independently verify claims or guarantee that a model follows every instruction.
